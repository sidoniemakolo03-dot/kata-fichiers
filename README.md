# Kata Fichiers - Ada Tech

Ce dépôt contient les exercices de manipulation de fichiers en Node.js réalisés dans le cadre de la formation Ada Tech.

## Exercices réalisés
- Exercice 1 : Écriture et lecture d'un fichier texte simple.
- Exercice 2 : Écrasement de fichier.
- Exercice 3 : Gestion de listes multilignes.
- Exercice 4 : Manipulation de données JSON.
- Exercice 5 : Création d'un bilan de journée dynamique.
